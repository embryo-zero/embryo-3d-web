# Embryo 3D Web

Embryo 3D Web is Embryo-Zero's fork of [Babylon.js](https://github.com/BabylonJS/Babylon.js) (9.36.0-17-g0ed204670b, commit 0ed204670b). It does 3D graphics and games in the browser.

- Our changes live on the `embryo` branch. The original license files (NOTICE.md, license.md) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
